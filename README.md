
# Ecommerce Data Pipeline

ETL-пайплайн для обработки заказов интернет-магазина с загрузкой данных в PostgreSQL, контролем качества, транзакционной синхронизацией и мониторингом выполнения.

## Технологический стек

- **Python 3.12** — реализация ETL-процесса.
- **Pandas** — обработка и очистка данных.
- **SQLAlchemy, psycopg2** — взаимодействие с PostgreSQL.
- **PostgreSQL 17** — хранение данных и аналитические витрины.
- **Docker** — контейнеризация базы данных.
- **Windows Task Scheduler** — автоматизация запусков.
- **Logging** — журналирование и мониторинг.

## Архитектура

```text
orders.csv
    |

    |
    v
```

## Основные возможности

### ETL и качество данных

- Загрузка исходных CSV-файлов.
- Исключение отменённых заказов и некорректных сумм.
- Проверка пропусков, дубликатов и корректности значений.
- Формирование отчётов Data Quality.
- Сохранение очищенных данных.

### PostgreSQL

- UPSERT по `order_id`.
- Атомарная загрузка с использованием транзакций.
- Откат изменений при ошибках.
- Опциональная полная синхронизация с Soft Delete.
- Проверка резкого сокращения количества записей перед Soft Delete.

### Аналитические витрины

**daily_sales**

Ежедневная аналитика продаж: количество заказов, выручка и средний чек (AOV).

**etl_monitoring**

Статистика запусков: успешность, ошибки, средняя продолжительность и количество загруженных строк.

**etl_health**

Текущее состояние ETL: последний запуск, зависшие процессы и актуальность успешной загрузки.

### Автоматизация и мониторинг

- Ежедневный запуск ETL по расписанию.
- Независимая проверка состояния каждые 30 минут.
- Регистрация запусков в `etl_run_history`.
- Коды завершения мониторинга.
- Логирование и ротация логов мониторинга.

## Локальный запуск

**1. Создать виртуальное окружение**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**2. Установить зависимости**

```powershell
pip install -r requirements.txt
```

**3. Настроить PostgreSQL**

Запустить PostgreSQL 17 в Docker, создать базу данных `ecommerce` и таблицы `orders`, `etl_run_history` с необходимой схемой.

**4. Настроить переменные окружения**

Скопировать `.env.example` в `.env` и указать параметры подключения к PostgreSQL.

**5. Запустить ETL**

```powershell
python pipeline.py
```

**6. Запустить мониторинг**

```powershell
python monitor.py
```

## Результаты тестирования

На тестовом наборе из 7 заказов:

- 4 заказа прошли бизнес-фильтрацию.
- 1 отменённый заказ исключён.
- 2 заказа с некорректными суммами исключены.
- 4 корректных заказа загружены в PostgreSQL.
- Проверены транзакционный откат, UPSERT, Soft Delete и мониторинг состояния ETL.
